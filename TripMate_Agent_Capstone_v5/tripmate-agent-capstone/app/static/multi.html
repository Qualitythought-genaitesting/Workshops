How this differs from the single-agent build

One coordinator parses your message and dispatches whichever specialists are relevant — flight, hotel and weather run concurrently, then the day-planner and budget agents run using their output. A combined request comes back with everything in one turn; reply "yes" to book every pending flight/hotel offer at once. Same guardrails as the classroom single-agent build (consent gate, spend limit, tool allow-list) — this is a different architecture on top of identical rules, not a way around them.
